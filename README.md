# thisshine 돌고래 VTuber 아바타 (Warudo용 VRM)

하늘색 긴 머리, 파란 눈, 돌고래 후드를 입은 VTuber 아바타입니다. 의상 8벌과 추가 표정 8종이 VRM 하나에 들어 있고, Warudo에서 단축키로 갈아입히고 표정을 켭니다.

## 다운로드

- 최신 버전: 저장소 맨 위의 `Dolphin_thisshine.vrm` (항상 최신으로 갱신됩니다. VRM 1.0, 약 81MB)
- 버전별 파일: [Releases](https://github.com/e7hao/thisshine/releases)에서 `Dolphin_thisshine_vA.B.C.vrm`을 받습니다. 예전 버전으로 돌아가고 싶을 때 씁니다.

버전 번호 규칙 (`vA.B.C`):
- `C` (0.0.1씩): 아바타 수정, 버그 수정. 예: v1.0.0 → v1.0.1
- `B` (0.1.0씩): 의상 추가. 예: v1.0.x → v1.1.0
- `A`: 아바타 자체를 크게 바꿀 때

## Warudo에 넣기

1. `Dolphin_thisshine.vrm`을 Warudo의 Characters 폴더에 넣습니다.
   - Warudo에서 캐릭터 에셋을 선택하고 **Open Characters Folder**를 누르면 이 폴더가 열립니다.
   - Steam 기본 설치 경로는 `C:\Program Files (x86)\Steam\steamapps\common\Warudo\Warudo_Data\StreamingAssets\Characters`입니다.
2. 캐릭터 에셋의 Source에서 `Dolphin_thisshine`을 고릅니다.
3. 표정을 가져오겠냐고 물으면 **Yes**를 누릅니다. 묻지 않으면 캐릭터 에셋 → Expressions → **Import VRM Expressions**를 누르고, 이어서 **Generate Key Binding Blueprint**를 누릅니다.

## 새 버전으로 업데이트할 때

Warudo는 캐릭터 에셋에 예전 버전의 표정 설정을 그대로 남겨둡니다. 파일만 바꾸면 의상이 안 보이거나 섞일 수 있습니다.

1. 캐릭터 에셋 → Expressions에서 이전 버전에서 들어온 표정(`outfit2`~`outfit8`, `paws`, `hood_off` 등)을 지웁니다.
2. **Import VRM Expressions**를 다시 누릅니다.
3. 아래 Layer 설정을 다시 합니다.

캐릭터 에셋을 새로 만들어도 됩니다.

## 꼭 할 설정: 의상 표정을 같은 Layer에 두기

Warudo는 VRM 표정을 가져올 때 `outfit2`~`outfit8`에 서로 다른 Layer(2, 3, 4, 5…)를 줍니다. 이대로 두면 두 의상이 동시에 켜져서 옷이 겹칩니다.

캐릭터 에셋 → Expressions에서 아래처럼 바꿉니다.

| 표정 | Layer |
|---|---|
| `outfit2` ~ `outfit8` | 모두 **10** (같은 숫자면 됩니다) |
| `paws` | 11 |
| `hood_off` | 12 |
| `o8ears`, `o6patch` | 13, 14 |
| 추가 표정 8종 | 각각 따로 (20~27 등) — 겹쳐 켤 수 있게 |

같은 Layer의 표정은 하나만 켜집니다. 다른 의상을 켜면 이전 의상은 자동으로 꺼집니다.

## 단축키

자동 생성된 **Expression Key Bindings** 블루프린트에 단축키가 들어 있습니다. 기본값은 Alt+숫자입니다. 바꾸려면 블루프린트에서 **On Keystroke Pressed** 노드의 Keystroke를 수정합니다.

- 의상 1(기본)로 돌아가기: **Alt+Backspace**(모든 표정 끄기)를 누르거나 켜진 의상 표정을 다시 누릅니다.
- 의상 3 맨손: `outfit3`을 켠 상태에서 `paws`를 끕니다. `paws`는 의상 3을 입었을 때만 의미가 있습니다.

## 문제 해결

### 눈 깜빡임이 잘 안 잡힐 때 (웹캠/MediaPipe)

모델의 깜빡임 블렌드셰이프(`eyeBlinkLeft`/`eyeBlinkRight`, VRM `blink`)는 정상입니다. 웹캠 트래킹은 눈 감은 값이 작게 들어오는 경우가 많아서, 감도를 올려야 합니다.

1. Assets 탭에서 **MediaPipe Tracker**를 선택합니다.
2. **Eye Blink Sensitivity**를 올립니다. 기본값은 1.2이고, 1.6~2.0을 추천합니다.
3. 한쪽 눈만 잘 감기면 **Linked Eye Blinking**을 켭니다. 두 눈이 같이 감깁니다.
4. 그래도 반만 감기거나 떨리면 **Configure BlendShapes Mapping**에서 `eyeBlinkLeft`/`eyeBlinkRight`를 조정합니다.
   - 왼쪽 입력 범위의 위쪽 값을 낮춥니다. 예: 0.7 → 0.5. 덜 감아도 끝까지 감깁니다.
   - 아래쪽 값을 평소 눈 뜬 값보다 조금 높게 둡니다. 눈을 뜨고 있을 때 떨리지 않습니다.
5. 조명이 어둡거나 안경에 빛이 반사되면 인식이 약해집니다. 얼굴 정면에 밝은 빛을 두면 좋아집니다.

### 의상을 바꿨는데 옷이 사라지거나 섞일 때

위의 **새 버전으로 업데이트할 때**와 **꼭 할 설정** 항목을 확인하세요.

## 트래킹

- 표준 VRM 휴머노이드 뼈대라서 Warudo의 웹캠(MediaPipe) 상반신·손 트래킹, 얼굴 트래킹이 그대로 됩니다.
- 모든 의상의 소매는 손목에서 끝나서 손가락 트래킹을 가리지 않습니다. 고양이 손 장갑은 `paws`로 끌 수 있습니다.
- 얼굴은 ARKit 52 블렌드셰이프를 지원합니다. iPhone 계열 트래킹도 쓸 수 있습니다.

## 물리

- 머리카락, 치마, 코트 자락, 유령 자락, 꼬리, 레그워머가 VRM 스프링으로 흔들립니다.
- 다리와 엉덩이에 충돌체가 있어서 치마와 자락이 다리를 뚫지 않습니다.
- 천끼리는 서로 부딪히지 않습니다(VRM 스프링의 한계). 팔을 등 뒤로 돌리면 팔이 천을 지나갈 수 있습니다.

## 알려진 점

- 입지 않은 의상은 투명 처리(MToon alpha cutout)로 숨깁니다. 표정을 켜면 해당 의상의 블렌드셰이프와 재질 알파가 함께 켜지고, 의상 1(후드티)은 투명해집니다.
- 의상은 반드시 표정(`outfit2`~`outfit8`)으로 바꿉니다. 블렌드셰이프(O2~O8)만 직접 바꾸면 옷이 투명한 채로 남습니다.
- 앉은 자세에서 치마가 허벅지를 지나갈 수 있습니다. 앉기 전용 치마는 v1.1.1에서 추가할 예정입니다.
- 일러스트 느낌을 위해 얇은 색 외곽선과 약한 림 라이트가 들어갔습니다 (얼굴 제외).
